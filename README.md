# MECCA CHAMELEON ESP

Minimal external ESP for MECCA CHAMELEON (UE5.6). Reads game memory
externally via `pymem` and draws an overlay with Qt5.

Features: names, 2D/corner boxes, dots, distance, snap lines, role labels,
invincible detection, optional radar, and optional "draw all" collectible
markers.

## Requirements

- Windows 10/11 x64
- Python 3.10+
- Game running as `PenguinHotel-Win64-Shipping.exe`

## Install

pip install -r requirements.txt
